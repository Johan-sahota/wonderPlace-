# 🏡 WonderPlace

A full-stack travel and accommodation platform where users can explore, create, edit, and review property listings.

## ✨ Features

- User registration and login
- Create and manage property listings
- Edit and delete listings
- Image uploads using Cloudinary
- Reviews and ratings
- Location-based maps
- Search listings by location
- Category-based listing filters
- Session-based authentication
- MongoDB database

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express.js
- EJS
- MongoDB
- Mongoose
- Passport.js
- Cloudinary
- Leaflet
- OpenStreetMap
